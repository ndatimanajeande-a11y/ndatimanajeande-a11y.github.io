# Ndatimana Jean de Dieu — Personal Portfolio

Official portfolio website for **Ndatimana Jean de Dieu**, a Computer Science student and emerging technology builder based in Rwanda.

## Live website

- Homepage: https://ndatimanajeande-a11y.github.io/
- Projects: https://ndatimanajeande-a11y.github.io/projects.html
- Articles: https://ndatimanajeande-a11y.github.io/blog.html

## Website features

- Responsive portfolio layout for desktop and mobile
- Project and article pages
- Search-engine metadata, canonical URLs, structured data and XML sitemap
- Accessible navigation, skip links and keyboard focus styles
- Read-aloud and browser-supported voice input
- Optional language translation and theme controls
- Reduced-motion support and subtle page animations
- Custom branded 404 page

## Publishing

This repository is configured as a GitHub Pages user site. Changes committed to the default branch are published at the homepage URL above. The sitemap is available at:

https://ndatimanajeande-a11y.github.io/sitemap.xml

## Clean-water project video

The Projects page includes a video player that expects a file named `clean-water-project.mp4` in the repository root. Add that MP4 to the root of this repository for the player to display the video. The video is a separate media asset and is not embedded in the HTML file.

## Content accuracy

Project descriptions distinguish early research and author-reported impact from independently verified results. The water-filtration research is preliminary and is not a certification of drinking-water safety.
